# Learned SNARC: from heuristic salience to trained attention
**2026-10-10 | Exploration, not a delivered capability**

The emerging category of low-latency typed decision models suggests revisiting SNARC as a **small trainable model**. But SNARC is already richer than binary routing: the five dimensional Surprise, Novelty, Arousal, Reward, Conflict framework controls memory capture, attention allocation and eventual learning from experience.

The standalone SNARC README documents tool+conversation hooks, PreCompact semantic capture, heuristic five-axis scoring, tiered memories, dream cycles and injection. Its discovered weakness—tool mechanics dominating meaningful decisions—is a prime outcome-based training case. Crucially, auto-promoted identity claims can be wrong: never use generated or re-injected claims as their own truth labels.

SAGE already has algorithmic **and neural** SNARC implementations; see the [June crossfeed audit](SNARC_SAGE_CROSSFEED_AUDIT_naive-opus-2026-06-27.md). Learned SNARC is an effort to inventory and reconcile interfaces, gather independently grounded delayed-outcome examples, benchmark small architectures and run shadow mode, not claim to invent neural salience.

**Principle:** learn *what deserves attention, of which kind, and at what cognitive cost*, preserving per-sensor/per-effector IRP salience keys, temporality, uncertainty, MRH/puzzle aggregation and governance separation. Deterministic filtering stays when sufficient. Model estimates never grant authority; Hestia gates actions.

Research route: existing-implementation/data audit → versioned key-level event/result receipt → deterministic and neural baseline replay → distilled tiny models → train for delayed attention utility + calibration + abstention → shadow tests on SNARC hooks, SAGE IRP and dev-SAGE ARC/SWE → reversible measured rollout. Compare end-to-end performance and missed consequential events, not marketing inference speed alone.

**Primary requirements and acceptance gates:** [Learned SNARC PRD](../prd/LEARNED_SNARC_PRD_2026-10-10.md). This repo owns the training/evaluation specification and standalone integration; SAGE owns IRP/attention integration; dev-SAGE owns competition experiments. Implementation status: proposed.
